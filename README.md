# Jogo da Velha - Campeonato "Melhor de N"

## Como executar
1 - INSTALAR O PYTHON:
Para que seja possível executar o jogo, será necessário haver o Python instalado no computador. Caso ainda não tenha, você pode baixá-lo no site oficial: https://www.python.org/downloads/

2 - ABRIR A PASTA DO JOGO:
Abra o Visual Studio Code e selecione a pasta onde está salvo o projeto do jogo da velha.

3 - EXECUTAR O JOGO: 
Abra o terminal do Visual Studio Code, acessando Terminal, e logo em seguida, Novo Terminal.

No terminal, execute o seguinte comando:

       python jogo_da_velha_.py

Pressione Enter para inicar o programa.

4 - UTILIZAR O MENU:
Após inicar o programa, siga as instruções exibidas no terminal para  escolher uma opção do menu e interagir com o jogo.

## Regras do jogo
1. O tabuleiro tem 3 linhas e 3 colunas.
2. Dois jogadores se alternam: X e O.
3. Na sua vez, informe a LINHA e a COLUNA de uma casa vazia (1 a 3).
4. Vence a partida quem completar uma linha, uma coluna ou uma diagonal com o seu símbolo.
5. Se o tabuleiro encher sem vencedor, é empate (não conta na série).
6. No campeonato "melhor de N", vence quem garantir a maioria das vitórias primeiro (2 na melhor de 3 | 3 na melhor de 5).
7. A cada partida, quem começa é alternado.
